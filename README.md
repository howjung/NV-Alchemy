<p align="center">식단 기록부터 정기 배송까지, 크루와 함께하는 AI 식단 관리 앱</p>

## 주요 기능

- **홈·기록** : 날짜별 식단·체중 기록, 목표 대비 현황
- **소셜** : 피드, 크루, 불꽃 보내기
- **쇼핑** : 가격 비교, 장바구니, 정기 배송
- **프로필** : 신체 지표, 목표와 계정 설정

> 개발 중입니다. 앱은 아직 서버와 연결되지 않았고 결제는 모의 결제이며, AI 추천은 연동 예정입니다.

## 기술 스택

Flutter · NestJS · PostgreSQL (Supabase)

## 실행

```bash
cd flutter_apps
flutter pub get
flutter run
```
