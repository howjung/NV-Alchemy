## 확정 필요 / 남은 확인

- **N13** 불꽃 보내기 횟수 제한과 좋아요와의 관계: 지금은 PRD 제안값(게시물당 1회, 좋아요와 별개)으로 구현했다. 확정되면 바꿔야 할 수 있다.
- 게시물 상세의 메뉴 위치(`Offset(-88, -14)`)는 화면에서 확인하지 못했다.
- 관심 없음·신고하기는 메뉴만 열리고 동작은 연결하지 않았다.
- 크루 최대 인원 선택값은 저장하거나 화면에 반영하지 않는다(기존 동작).
- 공유 데이터(`user_data.dart`)는 전역 변수이고 기기에 저장된다. 상태관리 방식이 정해지면 교체한다(임시, 사용자 확인함). 서버 연동 전. 결제 화면의 "새 배송지 추가"는 프로필 배송지 목록 화면을 열어 "추가"를 누르게 하는 임시 연결이다.
- 결제 수단 카드 행의 오른쪽 화살표(Figma)는 누를 화면이 없어 넣지 않았다. 카드 상세 화면이 정해지면 추가한다.
- 프로필 메인의 `ListTile` 경고는 v20에서 제거했다. 하위 화면은 확인 전이다.
- 확인 팝업의 빨간 확인 버튼(흰 글자 / `#D9534F`)은 대비가 3.96:1로 글자 기준 4.5:1에 못 미친다(15px 굵게). Figma 색이고 소셜·쇼핑·프로필 팝업이 공유하므로 디자인 확인 후 한 번에 바꾼다(예: 더 짙은 빨강).
- 팝업 버튼 높이 46은 Figma 값이다(iOS 44 이상, Android 권장 48 미만).
- 서버 연동 전이라 좋아요·댓글·불꽃·게시물은 앱을 다시 켜면 사라진다.
