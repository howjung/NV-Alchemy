- 좋아요를 누른 뒤의 채워진 하트(빨강 `#D9534F`)
- 댓글 시트(제목 "댓글", 목록, 입력창, 등록 버튼)
- 불꽃을 보낸 뒤의 버튼 상태("불꽃 보냄", 연한 배경)
- 크루 피드의 불꽃 보내기 버튼 (Figma 크루 피드에는 좋아요·댓글만 있음)
- 샘플 댓글, 새 댓글 작성자 "나", 새 게시물의 "방금 · 크루 인증" 문구, 새 게시물의 임시 사진

## 확정 필요 / 남은 확인

- **N13** 불꽃 보내기 횟수 제한과 좋아요와의 관계: 지금은 PRD 제안값(게시물당 1회, 좋아요와 별개)으로 구현했다. 확정되면 바꿔야 할 수 있다.
- 게시물 상세의 메뉴 위치(`Offset(-88, -14)`)는 화면에서 확인하지 못했다.
- 관심 없음·신고하기는 메뉴만 열리고 동작은 연결하지 않았다.
- 크루 최대 인원 선택값은 저장하거나 화면에 반영하지 않는다(기존 동작).
- 쇼핑·프로필 화면에서 `ListTile` 물결 효과 경고가 나온다(소셜 변경과 무관한 기존 문제).
- 서버 연동 전이라 좋아요·댓글·불꽃·게시물은 앱을 다시 켜면 사라진다.
